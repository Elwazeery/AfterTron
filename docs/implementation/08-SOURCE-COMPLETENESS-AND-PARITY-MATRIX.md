## 3. Verified Limitations & Honest Scope

1. **Adobe `.aep` Import (`crates/format/src/aep.rs`)**: Reads the RIFX/XFIR chunk container and extracts documented composition, footage, layer, transform, and keyframe chunks; proprietary binary effect blobs and encrypted presets are reported as warnings rather than silently dropped or falsely claimed as 100% compatible. Native `.ecproj` / `.ecprojx` and Lottie/SVG/PSD/Final Cut XML provide full lossless project storage and interchange.
2. **Optional AI Segmentation Weights (`crates/segment`)**: MobileSAM (`mobile_sam.pt`) and MediaPipe Face Landmarker (`face_landmarker.task`) are never auto-downloaded at startup or in tests; classical tracking and roto work offline out-of-the-box, and model downloads occur only on explicit user request with SHA-256 verification.
